# Source-system marks

These images identify the systems whose formats OCRS reads and writes. They are not OCRS
branding and are not included in OCRS's Apache-2.0 license. Their owners retain their
copyright and trademark rights; displaying them does not imply endorsement.

| File | Represented product and source |
|---|---|
| `openaireview.png` | [ChicagoHAI OpenAIReview](https://github.com/ChicagoHAI/OpenAIReview) |
| `reviewer3.png` | [Reviewer3](https://reviewer3.com/home) |
| `editorialmanager.png` | [Editorial Manager, Aries Systems](https://www.ariessys.com/software/editorial-manager/) |
| `scholarone.png` | [ScholarOne](https://clarivate.com/products/scientific-and-academic-research/research-publishing-solutions/scholarone/); the book is cropped from its wordmark |

These files were introduced in commit `379b912`. The original download URLs and separate
redistribution permissions were not recorded; the links above identify the products, not
independent license grants. OCRS therefore uses them only to identify, on its documentation
site, the formats it reads and writes, and leaves them (and `site/review-flow.png`, which
renders the same marks) out of its source archive and wheel. Reusers should check each
owner's brand terms before using the images in another product. The documentation also
references Google's mark at `https://www.gstatic.com/images/branding/product/2x/googleg_48dp.png`,
loaded from Google's servers rather than copied into this repository, to identify Google
DeepReview's format.
